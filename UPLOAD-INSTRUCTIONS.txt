1. Open the GitHub repository: trauma-informed-oregon/minorconsent
2. Choose Add file > Upload files.
3. Upload index.html from this folder.
4. GitHub will replace the existing index.html.
5. Commit directly to the main branch.
6. Wait for the Pages deployment to finish, then hard-refresh:
   Mac: Command + Shift + R
   Windows: Ctrl + Shift + R
