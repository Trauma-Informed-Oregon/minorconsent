MINOR CONSENT COMPLETE GITHUB PACKAGE

1. Download and unzip this package.
2. Open the GitHub repository Code page.
3. Choose Add file > Upload files.
4. Drag every file from this unzipped folder into GitHub.
5. GitHub will replace index.html and add/update the media files.
6. Keep all files at the repository root. Do not upload the ZIP itself.
7. Commit directly to main.
8. Wait for GitHub Pages deployment, then hard-refresh the live module.

Live site: https://trauma-informed-oregon.github.io/minorconsent/

Both index.html and minor-consent-module-1.html are included so the homepage and older direct links continue to work.
